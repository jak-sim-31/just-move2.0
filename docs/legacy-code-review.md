## 2. 화면 구성 (수정 전)

하단 탭: **홈 / 운동 / 기록 / MY** (4개)

### 2-1. 홈 `app/(tabs)/index.tsx`
| # | 요소 | 동작 |
|---|---|---|
| 1 | 로고 "JUST MOVE" + 문구 "생각은 그만, 일단 움직여요." | 고정 문구 |
| 2 | 통계 카드(네이비) | **오늘 완료** 수 / **예약 운동** 수 / **꼼지락 성공** 수 |
| 3 | 보상 요약 카드 | **Lv.n + 레벨 이름**, 누적 MOVE 포인트, **이번 주 활동일 n/7일**, 다음 레벨 진행 막대. 탭 → 기록 탭 |
| 4 | 오늘 예약 (있을 때만) | 예약 시각·운동 이름·목표 최대 2건. 탭 → 바로 영상 |
| 5 | 오늘 기록 (있을 때만) | 오늘 한 운동 최대 3개를 배지로 표시 (완료=체크, 부분=빈 원) |
| 6 | **[지금 움직이기]** (오렌지 큰 버튼) | 자세 선택으로 이동 |
| 7 | "지금 어떤 자세예요?" 빠른 선택 4칸 | 누워있다/앉아있다/서있다/걷고 있다 → 바로 시간 선택 |
| 8 | 예약 알림 | 앱이 열려 있을 때 30초마다 확인, 예약 시각이면 팝업 [나중에] [지금 시작] |

### 2-2. 운동 탭 `app/(tabs)/exercise.tsx`
- 제목 "지금 어떤 자세예요?", 부제 "현재 상태에 맞는 운동을 바로 추천해 드려요"
- 자세 카드 4개(설명: 침대·소파에 누운 상태 / 의자·바닥에 앉은 상태 / 서 있거나 서기 가능한 상태 / 산책·이동 중인 상태) → 시간 선택
- 하단 안내 "지금 자세에서 바로 시작할 수 있는 운동만 추천해요"

### 2-3. 운동 흐름 (`app/exercise/*`)
| 화면 | 요소 |
|---|---|
| 자세 선택 `position` | 뒤로, 단계 점(1/3), 자세 카드 4개 선택 후 **[다음]** |
| 시간 선택 `time` | 뒤로, 단계 점(2/3), 선택 자세 표시, **1분(스트레칭 1~2가지) / 3분(가벼운 운동 1가지) / 5분(운동 1~2가지) / 10분(운동 루틴 완성)**, 안내 "무리하지 않아도 돼요. 1분도 충분해요.", **[운동 추천받기]** |
| 맞춤 운동 추천 `recommendations` | 단계 점(3/3), 조건 칩(자세·n분 이내), 추천 카드 최대 3개(이름·난이도·요약·부위·시간·목표) **[상세 보기]**, 조건에 맞는 운동이 없으면 "가장 짧은 운동을 보여드려요" |
| 운동 상세 `detail` | 영상 썸네일 "영상 보기", 이름·요약·시간·부위·난이도·장비, 목표, **운동 방법**(단계별 설명), **주의사항**, **[시간 정하기]**(→예약), **[지금 움직이기]**(→영상) |
| 영상 `video` | 웹뷰로 외부 영상(모든 운동이 같은 네이버 블로그 클립), 웹에서는 "브라우저에서 열기", 목표·시간·부위, 안내 "끝까지 하지 않아도 괜찮아요. 움직인 만큼 기록할 수 있어요.", **[움직임 완료]** |
| 완료 `complete` (입력 단계) | "꼼지락 성공!", 운동 카드, **실제로 몇 번 했나요?**(숫자 입력), **메모(선택)**, **[기록 저장]**, **[인증사진 남기기]** |
| 완료 `complete` (보상 단계) | "오늘도 움직였어요!", 난이도 배지(가볍게/보통/도전 — 운동 고유 난이도에서 자동), **+n MOVE**, 누적·레벨·진행 막대, **새 배지 획득!**, **[기록 보기]** **[홈으로]** |
| 인증사진 `photo` | 카메라 촬영 / 사진 불러오기, 자세 메모, **[사진과 함께 저장]** / **[건너뛰기]**, "사진은 이 기기에만 저장되고 외부로 전송되지 않아요" |
| 운동 예약 `schedule` | 예약할 운동, 날짜(오늘/내일/직접 입력), 시·분, 목표량, 반복(한번만/매일 반복), **[예약 저장]**, "알림은 앱이 열려있을 때만 화면 내부에서 표시돼요" |

### 2-4. 기록 탭 `app/(tabs)/records.tsx`
상단 3구간 전환: **최근 기록 / 주간 통계 / 월간 통계**

| 구간 | 요소 |
|---|---|
| 최근 기록 | 최근 10건 목록: 상태(완료/부분)·체감 라벨, 운동 이름, 날짜·시각, 수행량, +MOVE, 메모, 사진 썸네일, **삭제** 버튼(확인 후 삭제). 비었을 때 "아직 운동 기록이 없어요 / 오늘 3분부터 시작해볼까요?" |
| 주간 통계 | 주 이동 [‹] [›] (**미래 주 이동 불가**), "이번 주 (m월 d일 ~ m월 d일)", 통계 상자 **완료 횟수 / 활동일 / 운동 시간 / 획득 MOVE / 최고 연속**, **난이도별**(가볍게·보통·도전 개수), **일별 활동 막대(월~일, 완료 횟수)**. 기록 없으면 "이번 주에는 아직 완료한 운동이 없어요." + [지금 움직이기] + 0 막대 |
| 월간 통계 | 월 이동 [‹] [›] (**미래 달 이동 불가**), 통계 상자(주간과 동일), 난이도별, **가장 많이 완료한 운동**, **월간 활동 캘린더**(운동한 날 네이비 칠, **하루 2회 이상이면 횟수 숫자**, 오늘 테두리), **활동일별 응원 문구**(0일 / 1~4일 / 5~9일 / 10~19일 / 20일 이상 5단계) |

### 2-5. MY 탭 `app/(tabs)/my.tsx`
- **나의 MOVE**: Level n·레벨 이름(움직임 준비 중 → 몸 깨우는 사람 → 꾸준한 움직임 → 루틴 메이커 → Just Mover), 누적 MOVE, 다음 레벨까지 남은 MOVE
- **획득한 배지 / 잠긴 배지**: 첫 움직임, 주 3회, 주 5회, 월 10일, **7일 연속**
- **통계 보기**: [주간 통계 보기] [월간 통계 보기] (둘 다 기록 탭으로 이동)

### 2-6. 운동 데이터 `constants/exercises.ts`
- 11개 운동: 벽 푸시업, 누워서 무릎 당기기, 앉아서 목·어깨 스트레칭, 제자리 무릎 높이 걷기, 앉아서 발목 돌리기, 누워서 다리 들기, 의자 스쿼트, 어깨 돌리기 & 가슴 펴기, 걸으면서 팔 스윙, 누워서 허리 비틀기, 까치발 들기
- 필드: 이름, 요약, 단계별 설명, 영상 URL, **자세(여러 개 가능)**, 시간(1·3·5분), 목표량·단위, 부위, 난이도(쉬움/보통/어려움), 장비, 주의사항, 사용 여부, 포인트
- 추천: 자세가 맞고 시간이 선택 시간 이하인 운동을 짧은 순으로 3개 (없으면 같은 자세 → 전체)

### 2-7. 보상 규칙 `constants/stats.ts`
- MOVE 포인트: 쉬움 10 / 보통 20 / 어려움 40
- 레벨 5단계 (0 / 100 / 300 / 600 / 1000 MOVE)
- 연속 기록(현재·최고), 주·월 활동일, 운동 시간 합계, 가장 많이 한 운동

## 3. 문제점

| 구분 | 위치 | 문제 |
|---|---|---|
| 실행 불가 | `constants/exercises.ts` | `SAMPLE_VIDEO_IDS` 미정의로 앱이 시작되지 않음 |
| 실행 불가 | `package.json` | Replit 모노레포 전용 의존성으로 단독 설치 불가 |
| 영상 | `video.tsx` | 모든 운동이 같은 외부 블로그 영상, 웹에서는 재생 안 되고 외부 브라우저로 이동, 재생 시간 측정 불가 |
| 기록 | `AppContext.tsx` | 기록을 최근 50건만 보관 → 월간 통계가 잘림 |
| 날짜 | `getTodayRecords` 등 | 일부 계산이 UTC 기준이라 한국시간 오전 0~9시 기록이 전날로 잡힘 (통계 쪽은 기기 시간 기준이라 서로 불일치) |
| 기록 기준 | `complete.tsx` | 실제로 움직였는지와 관계없이 [움직임 완료]만 누르면 기록 |
| 난이도 | `complete.tsx` | 사용자가 고르는 체감 난이도가 아니라 운동 고유 난이도로 자동 기록 |
| 알림 | `index.tsx`, `schedule.tsx` | 앱이 열려 있을 때 예약 시각 팝업만 가능 |
| 서버 | 전체 | 로그인·서버 저장 없음, 기기를 바꾸면 기록 소실 |

## 4. 기획서 기준 재사용 판단

| 기존 요소 | 판단 | 근거 |
|---|---|---|
| Expo/TypeScript 구조, 디자인 색상, 탭 구조 | **재사용** | 기획서 03 "기존 웹앱을 재사용·보완할 수 있는지 우선 검토" |
| 자세 선택(4종) | **재사용·수정** | 기획서 M-01 (명칭을 누워/앉아/서/걸으며로, 차 안은 앉아에 포함) |

| 맞춤 운동 추천 목록·운동 상세 | **제거** | 기획서 03 "추천 즉시 시작", 05 "별도의 사전 시청 단계는 두지 않는다", 확정 ③ |
| 영상 화면 | **재작성** | 기획서 M-03 (연속 재생, 이전/다음/그만하기, 실제 운동 시간) |

| 기록 탭 주간 통계의 일별 막대 그래프 | **유지** | 기획서 03 "주간 운동시간 그래프는 기존 앱의 현 상태를 가능하면 유지" (막대 기준을 완료 횟수 → 운동 시간으로 바꿀지는 확인 필요, 명세 Q-03) |

| '부분' 완료 표시 | **제거** | 기획서 01 "실패 표시를 드러내지 않음", 04 "1분 미만이면 보상 없이 격려" |
| MOVE 포인트·레벨·나머지 배지 | **확인 필요** | 기획서에 언급 없음 (명세 Q-01) |
