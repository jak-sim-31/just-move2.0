## 0. 한 줄 정의와 설계 원칙

**"고민하기 전에, 지금 1분만."** 운동을 꾸준히 못 하는 사람이 앉은 자리·누운 자리·서 있는 자리·걷는 중에 1분 영상을 따라 움직이게 하고, 쉬었다가 돌아와도 실패로 느끼지 않게 한다.

모든 화면·규칙은 아래 5가지 원칙으로 판단한다.

| # | 원칙 | 화면/로직에 미치는 영향 |
|---|---|---|
| P1 | **2탭 안에 운동 시작** | 홈 → 자세 → 시간 → 바로 영상. 추천 목록·상세 화면 단계를 없앤다 |
| P2 | **실패를 보여주지 않는다** | 연속 기록(streak), 쉰 날 수, 재시작 횟수, "미완료" 표시 금지. 작물은 시들지 않는다 |
| P3 | **돌아온 것을 환영한다** | 하루 이상 쉬고 오면 홈보다 먼저 환영 화면 |
| P4 | **1분이면 인정** | 실제 움직인 시간 1분 이상 = 움직인 날. 기준을 넘기면 무조건 칭찬과 보상 |
| P5 | **안전 우선** | 통증·어지러움 시 중단 안내 상시 노출, 차 안 동작은 "주차 중일 때만" |

### 검증 목표 (v1.0)
첫 사용 후 7일 안에 ① 운동을 이어가거나 ② 1일 이상 쉬었다가 돌아와 1분 이상 움직이는가?

- **성공 사용자**: 첫 사용일(D0)~D6 사이에 (a) 매일 1분 이상 운동 또는 (b) 1일 이상 공백 후 재운동이 1회 이상
- **보조 지표**: 복귀 사용자를 공백 기간 1일 / 2일 / 3일 이상으로 분류

### 베타테스트 성공 기준 (14일 운영)
| 지표 | 목표 | 정의 |
|---|---|---|
| 초기 사용률 | 90% 이상 | (정의 확인 필요) |
| 14일 참여 유지율 | 70% 이상 | 베타 마지막 3일 중 1회 이상 운동한 참여자 비율 |
| 운동 실천율 | 70% 이상 | 14일 중 7일 이상 운동한 참여자 비율 |
| 사용자 만족도 | 80% 이상 | 5점 만점 중 4점 이상 응답 비율 |
| 핵심 기능 정상 작동률 | 95% 이상 | (측정 방법 확인 필요) |

## 1. 대표 사용자와 사용 맥락

**페르소나 — 48세 여성 보험사 상담원**
- 출퇴근·외근 불규칙, 대기 시간이 짧고 정장 차림, 주차된 차 안에서도 사용
- 발바닥 통증 → 서서 하는 운동이 부담. 앉아서/누워서 동작 비중이 중요
- 목표는 체중 감량이 아니라 "몸이 가벼워지는 느낌"

**설계 시사점**
- 첫 화면에서 가장 큰 버튼은 "지금 움직이기" 하나
- 자세 선택에서 **앉아서**를 기본 강조(차 안 포함), 서서 동작은 발바닥 부담이 적은 동작 위주로 큐레이션
- 별도 "소리만 듣기" 기능은 만들지 않음 (기획서 원칙). 구령 자막을 화면에 넣을지는 §10 ⑩에서 확인
- 글자 크기 최소 16pt, 터치 영역 48px 이상, 3단계 이상 깊이 금지

## 2. 현재 MVP 진단

### 2-1. 재사용 판단 요약

**결론: 기존 프로젝트를 수정해서 사용하는 것이 효율적이다.** 단, 실행환경 정리와 데이터 계층 교체가 선행돼야 한다.

- 재사용 가치가 높은 것: Expo Router 화면 구조, 자세/시간 선택 UI, 기록 탭의 주간·월간 통계/캘린더 로직(`constants/stats.ts`), 디자인 토큰(`constants/colors.ts`)
- 교체가 필요한 것: 저장 방식(AsyncStorage만 사용 → 서버 + 로컬), 영상 재생(외부 블로그 링크 WebView → 1분 MP4 연속 재생 플레이어), 추천 로직, 보상 체계(MOVE 포인트/레벨/배지 → 물방울/농장)

## 3. 정보구조 (IA)

```
앱 실행
 ├─ [C-02] 재시작 환영 (조건부, 하루 1회)
 └─ 하단 탭
     ├─ 홈 [H-01]
     │   └─ 지금 움직이기 → [M-01] 자세 → [M-02] 시간 → [M-03] 영상 → [M-04] 완료
     │                                                              └─ [C-01] 로그인 권유 (첫 완료 1회)
     ├─ 기록 [H-02]   월간 캘린더 · 주간 그래프 · 운동 목록
     ├─ 농장 [F-01]   물주기 · 성장 · 수확 · 바구니 · 팁 카드
     └─ 마이 [P-01]   하루 1분 목표 · 알림 설정 · 계정/로그인 · 탈퇴
```

- 탭은 **홈 / 기록 / 농장 / 마이** 4개. 기존 "운동" 탭은 홈의 CTA와 중복이므로 **농장** 탭으로 교체한다.
- 운동 플로우(M-01~M-04)는 탭 바 없는 전체 화면 스택.

## 4. 화면 정의

### C-02 재시작 환영 (신규)
- **노출 조건**: 앱을 열었을 때, 마지막 운동일이 "어제보다 이전"이고(= 어제 운동 안 함), 오늘 아직 운동 기록이 없고, 오늘 환영 화면을 본 적 없을 때. 운동 이력이 없는 신규 사용자에게는 노출하지 않음.
- **구성**: 쉬기 전 그대로의 작물 이미지 · 환영 문구 1개 · [바로 1분 하기](→ M-01) · [홈으로 가기]
- **금지**: 쉰 날 수, 재시작 횟수, 연속 기록 초기화 문구
- **문구 선택 규칙**: 아래 2축으로 세그먼트를 정한 뒤, 해당 세그먼트 문구 중 최근 노출 2개를 제외하고 랜덤

| 축 | 값 |
|---|---|
| 휴식 기간 | 1~2일 / 3일 이상 |
| 이용 관계 | 오래 이용한 사용자(앱 이용 1개월 초과 **그리고** 운동한 날 20일 이상) / 그 외 |

→ 문구 그룹은 휴식 기간 2종 × 이용 관계 2종 = 총 4종.

### H-01 홈
위에서 아래로:
1. 오늘의 한마디 (시간대별 문구, 스프레드시트 관리)
2. **[지금 움직이기]** 큰 버튼 (화면 상단 1/3 안)
3. 농장 요약 — 현재 작물 단계 이미지, 물방울 n/7, 오늘 받은 물방울 n/5
4. 이번 달 — 운동한 날 수, 총 운동 분
5. 월간 캘린더 (운동한 날만 점 표시, 쉰 날은 아무 표시 없음)
6. 최근 운동 3건
7. 주간 운동시간 그래프 (기존 유지)

### M-01 자세 선택
- 4개 큰 카드: **누워서 / 앉아서 / 서서 / 걸으며**
- 앉아서 카드 보조문구: "의자·차 안(주차 중)"
- 마지막으로 선택한 자세를 강조(기본 포커스) — 다음 사용 시 고민 시간 단축

### M-02 시간 선택
- **1분 / 3분 / 5분** 3개 버튼. 탭 즉시 추천 로직 실행 → M-03 진입 (확인 단계 없음)

### M-03 운동 영상 (재작성)
| 요소 | 내용 |
|---|---|
| 상단 | 동작 이름, 진행 표시 (예: 2/3), 남은 시간 |
| 본문 | 구령+시범 1분 영상 (자동 재생, 연속 재생) |
| 하단 | [이전 동작] [그만하기] [다음 동작] |
| 상시 안내 | "통증이나 어지러움이 느껴지면 즉시 멈춰주세요" |
| 차 안 가능 동작 | "주차 중일 때만 해주세요" 배지 추가 표시 |
| 화면 꺼짐 방지 | Screen Wake Lock API (지원 안 되면 무시) |
| 영상 비율 | 세로(9:16)·가로(16:9) 모두 지원. 영상 비율에 맞춰 플레이어 영역을 자동 조정하고, 운동 목록에 영상 방향 값을 둔다 |

- **3·5분**: 1분 영상 3·5개를 플레이리스트로 연속 재생
- **다음 동작**: 현재 영상을 건너뛰고, 그 자리에 다른 추천 영상을 채워 **총 설정 시간(슬롯 수)은 유지**
- **이전 동작**: 바로 전 슬롯으로 돌아가 처음부터 재생
- **그만하기**: 확인 없이 M-04로 이동 (실제 운동 시간 기준 처리)

### M-04 운동 완료
| 경우 | 화면 |
|---|---|
| 실제 운동 1분 이상 | 칭찬 문구 · 인정된 운동 시간(1·3·5분) · 체감 난이도 3단계(**생략 가능**) · 물방울 +n 애니메이션 (한도 도달 시 "오늘 물방울은 다 모았어요") · [농장 가기] [홈으로] |
| 1분 미만 | 격려 문구만 ("움직이려고 한 것만으로도 충분해요") · 보상·기록 없음 · [다시 해보기] [홈으로] |

- 첫 번째 완료 직후 1회 **C-01 로그인 권유** 바텀시트

### C-01 로그인 권유
- "기록과 작물을 잃지 않도록 저장해 둘까요?" · [카카오로 계속] [구글로 계속] · **[나중에 하기]**
- 로그인 시 비회원 기록·농장 상태를 계정에 이어 붙임 (§6-4)

### F-01 나의 농장 (신규)
- 현재 작물(방울토마토) 성장 단계 이미지 — 물방울 0~7개 사용에 따라 단계 표시
- 보유 물방울 수, [물주기] 버튼(1개씩 사용)
- 7개를 주면 **수확** 연출 → 바구니 +1 → 팁 카드 1장 오픈 → 새 작물 시작
- 작물 바구니(누적 수확 수), 열린 팁 카드 목록

### H-02 기록
- 기존 `records.tsx`의 주간/월간 통계 유지, **연속 기록 제거**, 난이도 표기는 체감 난이도로 교체

### P-01 마이
- 목표: "하루 1분" 고정 표시(변경 불가)
- 알림: 켜기/끄기, 시작·종료 시각, 간격
- 계정: 로그인/로그아웃, 탈퇴(데이터 삭제 안내)
- 안전 고지·문의

## 5. 핵심 비즈니스 규칙

### 5-1. 운동 1회와 운동 시간 (확정)
- **운동 1회(세션)** = M-02에서 시간을 고른 시점부터 M-04 도착까지.
- **실제 운동 시간** = 세션 중 영상이 **재생 상태**였던 시간의 합. 초 단위로 저장.
  - 다음 동작으로 **넘긴 영상도 넘기기 전까지 재생한 시간은 포함**한다.
- **인정 시간** = 실제 운동 시간을 1·3·5분 단위로 내림한 값.

| 실제 운동 시간 | 인정 시간 |
|---|---|
| 1분 미만 | 0 (기록·보상 없음, 격려만) |
| 1분 이상 ~ 3분 미만 | 1분 |
| 3분 이상 ~ 5분 미만 | 3분 (예: 4분 30초 → 3분) |
| 5분 이상 | 5분 |

- 기록·통계(총 운동 분, 캘린더, 주간 그래프)는 **인정 시간** 기준. 실제 운동 시간(초)은 분석용으로 함께 저장한다.
- 저장값: 설정 시간, 실제 운동 시간(초), 인정 시간(분), 수행한 동작 목록(동작별 재생 초, 건너뜀 여부)

### 5-2. 움직인 날
- 한국시간 기준 하루에 실제 운동 합계가 아니라 **1분 이상 세션이 1회 이상** 있는 날.

### 5-3. 물방울·농장
| 설정 키 | 기본값 | 설명 |
|---|---|---|
| 지급 단위 | 인정 시간 1분당 1개 | 1분 → 1개, 3분 → 3개, 5분 → 5개 |
| `drop_daily_limit` | 5 | 하루 획득 한도. 운동은 한도와 상관없이 계속 할 수 있고 기록도 남는다 |
| `drops_per_harvest` | 7 | 수확에 필요한 물방울 |
| 성장 제한 | 없음 | 하루에 여러 번 수확 가능 |
| 감소 규칙 | 없음 | 쉬어도 시들거나 수확물 감소 없음 |

물주기는 자동이 아닌 **사용자 탭**으로 처리(농장 방문 유도). 단, 미사용 물방울은 계속 보관된다.

### 5-4. 추천 알고리즘
입력: 자세, 슬롯 수(1·3·5), 사용자별 동작 완료 횟수, 오늘 건너뛴 동작.

1. 후보 = 선택 자세에 해당하는 활성 동작
2. 동작 상태 분류: **새 동작**(0회) / **익히는 중**(1~4회) / **익힌 동작**(5회 이상, `mastered_threshold`)
3. 첫 사용자(완료 0회)의 1번 슬롯은 `is_first=true` 동작
4. 1분: 익히는 중 우선 → 없으면 새 동작 → 없으면 익힌 동작
5. 3·5분: 익히는 중과 새 동작을 `new_ratio`(기본 0.3) 비율로 혼합, 익힌 동작은 슬롯당 낮은 확률(기본 10%)로만 노출
6. 직전 슬롯과 **같은 부위가 연속되지 않게** 배치 (불가능하면 허용)
7. 오늘 건너뛴 동작도 후보에서 빼지 않음 (가중치만 낮춤)
8. 후보가 슬롯 수보다 적으면 반복 허용

### 5-5. 알림 (확정: 기획서 원안)
- 기본값: **오전 9시~오후 8시, 매시 정각**. 사용자가 시작·종료 시각, 간격, 켜기/끄기를 변경할 수 있다.
- 오늘 물방울 5개를 모으면 그날 알림 중지.
- 문구 2종 세그먼트: 오늘 아직 안 움직인 사람 / 이미 움직인 사람.
- 미루기(1시간 뒤 / 3시간 뒤 / 오늘은 그만): **iOS 웹 푸시는 알림 내 액션 버튼을 지원하지 않으므로**, 알림 탭 시 열리는 앱 내 시트에서 선택하도록 구현 (Android Chrome은 액션 버튼 병행 가능).
- iOS는 16.4 이상 + **홈 화면에 추가한 웹앱**에서만 푸시 가능 → 첫 로그인/알림 설정 시 "홈 화면에 추가" 안내 필요.

### 6-3. 지표 (관리자 화면)
- **코호트**: 첫 운동일 기준 D0~D6
- **7일 성공률** = 성공 사용자 / 코호트 사용자 (성공 정의 §0)
- **복귀 분포**: 공백 1일 / 2일 / 3일 이상 후 재운동한 사용자 수·비율
- 보조: 일별 활성, 세션당 실제 운동 시간, 1분 미만 이탈 비율, 영상별 건너뛰기율, 알림 클릭률
- 추적 이벤트: `app_open`, `welcome_shown`, `session_start`, `video_skip`, `video_prev`, `session_stop`, `session_complete`, `drop_earned`, `water`, `harvest`, `login_prompt_shown`, `login_success`, `notif_click`, `notif_snooze`

### 6-4. 비회원 → 회원 이전
- 첫 실행 시 기기에 **익명 사용자**를 생성해 서버에 바로 저장(익명 인증). 로그인하면 익명 계정을 소셜 계정에 **연결(link)** 하여 기록·농장이 그대로 이어지게 한다.
- 이미 다른 기기에서 가입한 계정으로 로그인하는 경우: 세션·수확 수는 합산, 미사용 물방울은 합산, 작물 진행도는 큰 값 채택.

### 6-5. 탈퇴 처리 (확정)
- 계정·로그인 정보(소셜 식별자, 푸시 구독 정보 등)는 **즉시 삭제**한다.
- 운동 기록·이벤트는 사용자 식별자를 끊어 **누구 것인지 알 수 없게 바꾼 뒤** 통계 집계에만 사용한다.

## 7. 기술 구성 제안

| 영역 | 제안 | 이유 |
|---|---|---|
| 프론트 | 기존 Expo Router 유지, **웹(PWA) 우선 빌드** | 코드 재사용, 기획서가 웹앱 기준 |
| 백엔드/인증/DB | **Supabase** (Postgres + Auth + Edge Functions) | 익명 로그인→소셜 연결, 카카오·구글 OAuth 기본 지원, 무료 플랜으로 베타 가능 (확장 시 월 $25~) |
| 영상 | 1분 MP4(가로 720p 이하) + HTML5 video, Supabase Storage 또는 Cloudflare R2 | 연속 재생·재생시간 측정·자동재생 제어가 YouTube/블로그 임베드보다 확실 |
| 콘텐츠 관리 | Google Sheets → 주기적 동기화 함수(Edge Function, 15분 간격 또는 수동 버튼) | 운영자가 스프레드시트로 관리 |
| 웹 푸시 | Web Push(VAPID) + Service Worker, 발송은 스케줄 함수 | 별도 푸시 서비스 비용 없음 |
| 관리자 지표 | DB 뷰 + Looker Studio(또는 Metabase) | 별도 관리자 화면 개발 최소화 |

**월 운영비 개략 (베타 100명 규모)**: Supabase 무료~$25, 영상 스토리지/전송 수 달러 이내(20개 × 약 10MB), 도메인 연 1~2만원. 정확한 산정은 범위 확정 후.
