# JUST MOVE 디자인 명세

> 기준: 수정 전 화면(`357e0d7`)의 디자인을 그대로 이어받는다. 새로 생기는 화면(영상 재생, 농장, 재시작 환영, 로그인 등)도 같은 규칙으로 만든다.
> 관련 문서: [service-spec.md](service-spec.md) (화면 기능) · [legacy-code-review.md](legacy-code-review.md) (수정 전 화면 목록)
> 최종 수정: 2026-10-20

## 1. 디자인 원칙

1. **수정 전 화면과 같은 느낌**: 밝은 회색 배경 위 흰 카드, 네이비 주색, 오렌지 강조. 카드·버튼 모양과 크기를 그대로 쓴다.
2. **가장 중요한 행동은 오렌지 한 개**: 한 화면에 오렌지 큰 버튼은 하나만 둔다 (지금 움직이기, 다음 등).
3. **실패처럼 보이는 색을 쓰지 않는다**: 빨강(destructive)은 삭제·탈퇴 확인에만 쓴다. 쉰 날, 1분 미만, 그만하기에는 쓰지 않는다. 〔R01-08〕
4. **눌렀다는 느낌**: 누르면 살짝 작아지거나(0.95~0.97) 흐려지고(0.85), 중요한 동작에는 진동을 준다.

## 7. 화면별 레이아웃

### H-01 홈

**원칙**: 휴대폰에서 스크롤 없이 보이는 첫 화면에 가장 중요한 행동(움직이자는 메시지 + [지금 움직이기])을 맨 위에 둔다. 수정 전 앱도 지금 움직이자는 메시지와 버튼이 가장 먼저 보였다. 같은 일을 하는 버튼은 하나만 둔다.

**첫 화면 (375×812 기준, 스크롤 없이)**
1. **머리 줄**: 왼쪽 로고 24/800 + 문구 "생각은 그만, 일단 움직여요." 12 / 오른쪽 **알림 버튼**(알약 모양, 높이 40, 테두리 1): 켜짐이면 `notifications`(accent) + "14시 알림" / "내일 9시 알림", 꺼짐이면 `notifications-off-outline` + "알림 꺼짐"(`secondary` 배경). 누르면 P-02 알림 설정
2. **움직이기 카드**(네이비 `primary`, 둥근 16, 여백 20, 간격 12)
   - 오늘의 한마디: 흰색 20/800
   - 안내: 자세 아이콘 4개(지름 26, `rgba(255,255,255,0.15)` 원, 누를 수 없음) + "누워서·앉아서·서서·걸으며, 지금 자세 그대로 1분" 13 — **자세를 고르는 버튼이 아니라 [지금 움직이기]로 이끄는 문구**. 자세는 다음 화면(M-01)에서 고른다
   - **[지금 움직이기]**: 오렌지, `flash` 24 + 18/800, 위아래 18, 오렌지 그림자
   - [멈춘 운동 이어서 하기]: 멈춘 운동이 있을 때만, 흰 테두리 버튼
   - 오늘 상태 한 줄 12: "오늘 3분 움직였어요 · 물방울 3/5" / "오늘의 첫 1분을 시작해 볼까요? · 물방울 0/5"
3. **오늘 예약**: 있을 때만. 예약 카드 최대 2개 + [+ 예약하기]
4. **농장 카드**(밭 배경 `#EAF5EC`, 둥근 14): 작물 그림 84 + "나의 농장" 13 + **"수확까지 물방울 n개"** 17/800(개수는 `#3B9AE1`) + 진행 막대 6 + "보유 물방울 n개 · 바구니 n개". 첫 화면 아래쪽에 오도록 둔다

**스크롤하고 싶게 만드는 장치**
- 농장 카드의 "수확까지 n개"와 자라는 작물: 조금만 더 하면 수확한다는 신호
- 그 아래 통계 카드 윗부분이 화면 끝에 살짝 걸려 아래에 더 있다는 것을 보여 줌

**스크롤 아래**
5. 오늘 통계 카드(네이비): 오늘 완료 / 예약 운동 / 꼼지락 성공
6. 레벨 카드(Lv·누적 MOVE·이번 주 활동일·진행 막대)
7. 이번 달: 통계 상자 2개(운동한 날 / 총 운동 시간) + 월간 캘린더 카드
8. 최근 운동 3건 + [전체 보기]
9. 이번 주 운동 시간 막대 그래프

수정 전 홈의 "지금 어떤 자세예요?" 4칸은 [지금 움직이기]와 같은 일을 하는 중복이라 버튼으로 두지 않고, 2번 카드의 안내 문구로 바꿨다.

### H-02 기록
머리(제목 "운동 기록" + 세그먼트) 고정, 아래 내용 스크롤 — 수정 전과 동일
- 최근 기록: 기록 카드 목록
- 주간 통계: 기간 이동 → 통계 상자 2줄 → "체감 난이도별" 칩 → "일별 운동 시간" 막대
- 월간 통계: 기간 이동 → 통계 상자 → 칩 → 가장 많이 한 운동 → "월간 활동" 캘린더 → 응원 메시지 상자

### 운동 탭 / M-01 자세 선택
- 운동 탭: 제목 + 부제 + 자세 카드 4개(세로) + 안내 상자("지금 자세에서 바로 시작할 수 있는 운동만 추천해요")
- M-01: 흐름 머리(단계 점 1/2) + 제목 + 부제 + 자세 카드 4개. 카드를 누르면 바로 다음 (선택 표시가 잠깐 보인 뒤 이동)

### M-02 시간 선택
흐름 머리(단계 점 2/2) → 선택 자세 알약(`secondary`, 체크 아이콘 `success`) → 제목 → 부제 → 2열 시간 카드(너비 47%, 높이 130, 아이콘 28, 숫자 22/800, 설명 12) 3개 → 안내 "무리하지 않아도 돼요. 1분도 충분해요." → 누르면 바로 영상

### M-03 운동 영상
수정 전 영상 화면 구성 유지:
1. 네이비 머리: [‹] + 가운데 동작 이름(흰 16/700) + 오른쪽 "n/전체"
2. 검은 영상 영역: 남은 높이를 채움. 세로 영상은 높이에 맞추고 가로 영상은 너비에 맞춤. 누르면 일시정지(가운데 `play-circle` 72 + "탭해서 이어서 하기")
3. 영상 진행 막대(4)
4. 정보 영역(`background`, 여백 20, 간격 12):
   - 목표 / 시간 / 부위 줄 (기본 카드, 가운데 정렬 3칸 + 세로 구분선, 라벨 11/600 + 값 16/700) — 시간 칸은 "남은 m:ss"
   - 차 안 가능 동작: 알약(`#FEF5E7` 배경, `car-outline` + "주차 중일 때만 해주세요" 13/700 `#B45309`)
   - 안내 상자: "끝까지 하지 않아도 괜찮아요. 움직인 만큼 기록할 수 있어요."
   - 주의사항 12 `textSecondary`
   - 안전 문구 "통증이나 어지러움이 느껴지면 즉시 멈춰주세요" 13/600 `text`
5. 하단 바: [이전 동작] [그만하기] [다음 동작] — 왼쪽·오른쪽 테두리 버튼(`primary`), 가운데 채운 버튼(`success`, `checkmark-circle`). '그만하기'는 실패가 아니라 **마치기**의 의미라 초록을 쓴다

### M-04 운동 완료 (수정 전 2단계 구성)
- 1단계(입력): 초록 원(100, `successLight` + 체크 64) → "꼼지락 성공!" 28/800 `success` → "오늘도 실제로 움직였어요" → 운동 카드(라벨 "운동" + 동작 이름들 18/800 + 인정 시간) → "오늘 운동은 어땠나요?" 체감 난이도 칩 3개(선택 시 `primary`) → "실제로 몇 번 했나요? (선택)" 동작별 숫자 입력 → "메모 (선택)" → 하단 바 [인증사진 남기기](테두리) + [기록 저장](채움 `primary`)
- 2단계(보상): 초록 원 → "오늘도 움직였어요!" 22/800 → 보상 카드(동작 이름 + 체감 칩 + **물방울 +n** 상자(`#3B9AE1`) + **+n MOVE** 상자(`primary`) + 누적) → 레벨 카드 → 새 배지 상자(있을 때) → "오늘 물방울은 다 모았어요"(한도) → 하단 바 [기록 보기](테두리) + [농장 가기](채움 `accent`) + 그 아래 [홈으로] 글자 버튼
- 1분 미만: 원(`secondary` + 하트 아이콘) → 격려 문구 → [다시 해보기](`accent`) [홈으로](테두리)

### 인증사진
수정 전 화면 그대로: 흐름 머리("인증사진 남기기" + [건너뛰기]) → 사진 영역 → [카메라 촬영] [사진 불러오기] → 자세 메모 → 안내 문구 → [사진과 함께 저장]

### 운동 예약
수정 전 화면 그대로: 흐름 머리("운동 예약") → 예약할 운동 카드(네이비) → 날짜 칩(오늘/내일/직접 입력) → 시·분 가로 스크롤 → 목표량 숫자 입력 → 반복 칩(한번만/매일 반복) → 안내 상자 → [예약 저장]

### F-01 나의 농장
탭 화면 머리("나의 농장") → 밭 카드(`#EAF5EC`, 둥근 16, 작물 그림 190 + "물방울 n/7" 18/800 + 진행 막대) → 보유 물방울 카드(물방울 아이콘 28) → [물주기](채운 버튼 `#3B9AE1`, 높이 56) 또는 [운동하러 가기](`accent`) → "작물 바구니" 섹션(토마토 아이콘 줄 + "방울토마토 n개") → "팁 카드" 섹션(메뉴 버튼 모양 + 종류 알약). 수확 시 가운데 상자(토마토 72 + 제목 22/800 + 새 팁 카드 상자 + [팁 카드 보기] [닫기])

### C-02 재시작 환영
탭 바 없음. 위 여백 48 → 작물 그림 168 → 환영 문구 24/800 가운데 → 아래 [바로 1분 하기](`accent`, 높이 60) [이어서 하기](테두리, 있을 때) [홈으로 가기](글자 버튼)

### P-01 MY
제목 "MY" → 로그인 상태 카드 → "나의 MOVE" 레벨 카드(네이비, 둥근 16, 여백 20: 위 "Level n"(흰 0.7, 12/700) + 레벨 이름 18/800 / 오른쪽 누적 32/800 + "MOVE" / 진행 막대 8 / "다음 레벨까지 n MOVE 남음") → "나의 목표" 하루 1분 카드 → "획득한 배지" → "잠긴 배지" → "통계 보기" 메뉴 2개 → "설정" 메뉴(알림 설정 / 운동 예약 목록 / 계정·탈퇴) → 안전 고지 메시지 상자 → 버전

### P-02 알림 설정 / P-03 계정·탈퇴 / L-01 로그인
흐름 머리(이름) + 기본 카드 줄 목록. 로그인 버튼: 카카오 `#FEE500`, 구글 테두리 버튼, [나중에 하기] 글자 버튼.

### 정각 알림 안내 (앱 안)
가운데 상자: 문구 20/800 → [지금 1분 하기](`accent`) → [1시간 뒤] [3시간 뒤](테두리) → [오늘은 그만](글자). 예약 시각 알림도 같은 상자: "운동 시간이에요!" + 운동 이름·목표 + [지금 시작] [나중에].

## 9. 접근성
- 모든 버튼에 읽을 수 있는 이름(라벨)을 단다
- 터치 영역 44 이상
- 색만으로 구분하지 않는다 (캘린더는 칠 + 굵은 숫자, 선택은 색 + 체크)
